Developer Documentation

Integration guide for Student Verification and Payment Notification.

Overview

Authentication: All requests must include the header x-api-key.

x-api-key: sk_live_xxxxxxxxxxxxxxxxxxxxxxxx

Phase 1: Verification

Verify a student exists before accepting payment.

POST .../functions/v1/bank-gateway

Request Body:

{ "action": "verify_student", "student_id": "GHMS25101" }

Phase 2: Payment Notification

Notify the system immediately after a successful transaction.

POST .../functions/v1/payment-webhook

Request Body:

{ "student_id": "GHMS25101", "amount": 500.00, "transaction_ref": "TXN-12345678", "payment_date": "2023-10-27T10:00:00Z" }

Response Codes:

  • 200 OK: Payment recorded successfully.
  • 404 Not Found: Student ID is invalid.
  • 409 Conflict: Transaction Reference already exists (Duplicate payment).
